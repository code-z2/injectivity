# Motion

> Premium interactive web sections — physics-based, cursor-responsive, impossible to replicate. Each section ships as a detailed Markdown specification file, unlocked by a plan, that developers can use to recreate it exactly.

## What Motion is

Motion is a subscription library of premium animated web sections. Unlike template libraries, every section is a unique, hand-crafted, physics-based interactive scene. Sections respond to cursor movement using spring physics (not CSS transitions), feature wave propagation, click impulses, and other interactive effects that are intentionally hard to replicate.

Each section ships as a detailed `.md` specification file containing the full implementation: HTML structure, CSS, JavaScript with raw `requestAnimationFrame` physics, and entrance animations using GSAP. Plans unlock the complete creative asset for use in any project — including client and commercial work.

## Quality standard

Every section must pass this test: "Would I stop scrolling and try to figure out how this was made?"

Sections that look like generic AI output (particles, dot grids, gradient text, counting numbers) do not ship.

## Tech stack used in sections

- Vanilla JavaScript (no framework dependency for the section itself)
- GSAP for entrance animations and ScrollTrigger
- Raw `requestAnimationFrame` for physics simulations
- Spring constants and damping (not CSS transitions)
- Canvas 2D for mesh and particle work
