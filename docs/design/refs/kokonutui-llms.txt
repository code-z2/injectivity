# Kokonut UI

> Kokonut UI is a free, open-source library of React components built with Tailwind CSS, Motion and shadcn/ui. Install any of them with one command or one prompt.

Components are installed with the shadcn CLI, e.g.
`npx shadcn@latest add @kokonutui/card-flip`. Each page below links to
its Markdown source, which includes the install command and the full
component source code.

To set Kokonut UI up in a project, follow https://kokonutui.com/setup.md.

- [Installation](https://kokonutui.com/docs.md): Install Kokonut UI components in any React or Next.js project with the shadcn CLI, using namespaces or direct registry URLs. No extra setup required.
- [Agents](https://kokonutui.com/docs/agents.md): Use Kokonut UI with Claude Code, Cursor, VS Code or Codex. Connect the shadcn MCP server, add a rules file, and give your agent the docs as Markdown.
- [Changelog](https://kokonutui.com/docs/changelog.md): New and updated Kokonut UI components, release by release, with a link to each component and its pull request.
- [Templates](https://kokonutui.com/docs/templates.md): Full websites built with Kokonut UI, available with Kokonut UI Pro. Open a live preview, or get the source when one fits your project.
- [Pro components](https://kokonutui.com/docs/pro.md): A look at Kokonut UI Pro, the larger paid collection. Heroes, page sections, app UI, cards, inputs, forms, pricing and full pages, shown as stills.

- [Background Paths](https://kokonutui.com/docs/backgrounds/background-paths.md): A ribbon of lines in one color that keeps flowing at any size and parts around the cursor.
- [Shape Hero](https://kokonutui.com/docs/backgrounds/shape-hero.md): A landing hero where shapes drop in, pile up under the headline and can be grabbed and thrown.
- [Wind](https://kokonutui.com/docs/backgrounds/flow-field.md): Streamlines that part around the cursor, swirl in its wake and scatter on click, built with React and Canvas.
- [Topo Background](https://kokonutui.com/docs/backgrounds/topo-background.md): A living contour map that drifts, rises under the cursor and ripples on click, built with React and Canvas.
- [Drape Background](https://kokonutui.com/docs/backgrounds/drape-background.md): A pleated curtain in a breeze that you can push and pull, built with React, WebGL and a cloth simulation.
- [Halftone Background](https://kokonutui.com/docs/backgrounds/halftone-background.md): Any image, or a lit sphere, printed as a halftone dot screen, with a loupe that looks closer under the cursor, built with React and canvas.
- [Ink Background](https://kokonutui.com/docs/backgrounds/ink-background.md): A hero written in ink on water. Stir it and the letters bleed, click to drop ink, and the headline gathers itself again. Built with WebGL.
- [Caustics Background](https://kokonutui.com/docs/backgrounds/caustics-background.md): A hero on the floor of a pool. Light ripples across it, clicks drop rings that bend the light, and the headline's shadow wobbles below.
- [Rain Glass Background](https://kokonutui.com/docs/backgrounds/rain-glass-background.md): A hero seen through a rainy window. Drops gather and run, each a tiny lens on the view, and dragging wipes the fog off the glass.
- [Rhythm Hero](https://kokonutui.com/docs/backgrounds/rhythm-hero.md): A health and sleep app hero with hairline rings breathing a 4-7-8 cycle, a week of sleep-stage bars and calm stats. Part of Kokonut UI Pro.
- [Dither Reveal Hero](https://kokonutui.com/docs/backgrounds/dither-reveal-hero.md): An image generation hero where a drawn scene resolves from coarse dither to full detail as the prompt types. Part of Kokonut UI Pro.

- [Detent Dial](https://kokonutui.com/docs/inputs/detent-dial.md): Rotary knob that clicks from notch to notch and coasts when flicked, built with React and Motion.

- [Liquid Slider](https://kokonutui.com/docs/inputs/liquid-slider.md): A vertical slider you fill like a glass, with a sloshing surface and rising bubbles.
- [Signature Pad](https://kokonutui.com/docs/inputs/signature-pad.md): A signature field with a sprung pen tip, speed-weighted ink and SVG output.
- [Time Zone Planner](https://kokonutui.com/docs/inputs/timezone-planner.md): Find a meeting time across time zones. Turn the meeting round a 24-hour dial where each ring is someone's day.

## AI

- [AI Components](https://kokonutui.com/docs/ai.md): Free React components for AI apps: chat inputs with model pickers, tool approvals, citations, diff review, streaming states and more, built with Tailwind CSS.
- [AI Input Selector](https://kokonutui.com/docs/ai/ai-prompt.md): AI chat input with a model menu, a separate Effort control, file chips you can drop or paste, a / command menu, and Stop while replying.
- [AI Input Search](https://kokonutui.com/docs/ai/ai-input-search.md): AI composer with a Tools menu (browse, investigate, draft, run code, reason), a model picker and a live trace that stacks each source's avatar as it is read.
- [AI State Loading](https://kokonutui.com/docs/ai/ai-loading.md): Agent progress as a list of steps with a live log, elapsed time and a summary when done.
- [AI Text Loading](https://kokonutui.com/docs/ai/ai-text-loading.md): AI thinking text with a soft wave through the letters and words that swap letter by letter.
- [AI Voice](https://kokonutui.com/docs/ai/ai-voice.md): Voice input with a scrolling waveform, then a take you can play back, discard or send.
- [AI Tool Approval](https://kokonutui.com/docs/ai/ai-tool-approval.md): Approve or deny an agent's tool calls. Destructive calls need a press and hold, and decided calls fold into a trace with their output.
- [AI Context Meter](https://kokonutui.com/docs/ai/ai-context-meter.md): How full the context window is, as a ring in the prompt footer that opens a breakdown by source and compacts when it fills.
- [AI Inline Citations](https://kokonutui.com/docs/ai/ai-citations.md): An answer with source chips beside each claim. One preview glides between chips and lights up the sentence it backs.
- [AI Diff Review](https://kokonutui.com/docs/ai/ai-diff-review.md): A coding agent's edits streaming in file by file, then reviewed per file with accept, reject and undo.
- [AI Model Selector](https://kokonutui.com/docs/ai/ai-model-selector.md): Pick a model and how hard it thinks. Effort is a detent track that reshapes for each model and keeps your level when you switch.
- [AI Token Alternatives](https://kokonutui.com/docs/ai/ai-token-alternatives.md): An answer where every unsure word shows what else the model weighed. Pick another word and the reply writes itself again from there.
- [AI Conversation Branches](https://kokonutui.com/docs/ai/ai-branches.md): A chat where editing a message starts a new branch. A small tree beside it shows every version, and you can jump between them.
- [AI Agent Lanes](https://kokonutui.com/docs/ai/ai-agent-lanes.md): A lead agent hands work to sub-agents that run side by side. Each gets a lane of tool calls, and you can scrub through the whole run.
- [AI Inline Edit](https://kokonutui.com/docs/ai/ai-inline-edit.md): Select text in a document and ask AI to rewrite it. The edit streams in place as a word-level diff you accept, discard or try again.
- [AI Message Queue](https://kokonutui.com/docs/ai/ai-message-queue.md): Keep typing while the agent works. Follow-ups stack above the composer, where you can reorder, edit or send one now, and go in one by one when the run ends.
- [AI Redact](https://kokonutui.com/docs/ai/ai-redact.md): Masks names, emails, card numbers and keys as placeholders before a prompt is sent, then fills the real values back into the reply.
- [AI Memory](https://kokonutui.com/docs/ai/ai-memory.md): An assistant that saves what it learns about you into a memory list. New facts replace the ones they contradict, and you can edit or forget any of them.
- [AI Autocomplete](https://kokonutui.com/docs/ai/ai-autocomplete.md): A text box that suggests how your sentence ends in grey after the caret. Tab takes it all, the right arrow takes one word, and typing the same letters keeps it.
- [Slash Command Menu](https://kokonutui.com/docs/ai/slash-command-menu.md): A chat composer with slash commands, a hint bar that spells out each argument and a menu that offers values for it. Part of Kokonut UI Pro.
- [Image Generation Card](https://kokonutui.com/docs/ai/image-generation-card.md): An AI image panel where Generate resolves the picture from coarse pixel blocks to sharp with a step counter, then four variations land. Part of Kokonut UI Pro.

- [Typing Text](https://kokonutui.com/docs/texts/type-writer.md): Typewriter text that makes the odd typo and corrects it, erases by selecting, and blinks its caret only when idle, built with React and Motion.
- [Dynamic Text](https://kokonutui.com/docs/texts/dynamic-text.md): Morphing text where shared letters travel, old ones fall and new ones land, with decode and cycle modes.
- [Glitch Text](https://kokonutui.com/docs/texts/glitch-text.md): Flat text that cuts into hard-shifted bands with a thin red/cyan split, on idle, hover or text change.
- [Extruded Text](https://kokonutui.com/docs/texts/swoosh-text.md): Zinc 3D extruded text lit by your pointer, with letters that press in like keycaps.
- [Plucked Text](https://kokonutui.com/docs/texts/plucked-text.md): A headline sitting on a string you can pluck, strum and let ring, built with React and real string physics.
- [Cradle Text](https://kokonutui.com/docs/texts/cradle-text.md): A headline hung like a Newton's cradle, so a knock on one letter clacks through the word, built with React and pendulum physics.
- [Spoiler Text](https://kokonutui.com/docs/texts/spoiler-text.md): Inline text hidden under drifting specks, like a chat spoiler. A click blows the specks away from the point you touched.
- [Marker Text](https://kokonutui.com/docs/texts/marker-text.md): Hand-drawn highlights, underlines, circles, boxes and strikes that draw themselves in reading order when the text comes into view.

- [Kinetic Type Hero](https://kokonutui.com/docs/texts/kinetic-type-hero.md): A studio hero where an edge-to-edge headline sets itself in and leans away from the cursor. Part of Kokonut UI Pro.
